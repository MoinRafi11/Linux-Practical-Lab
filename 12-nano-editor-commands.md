# Linux `nano` Editor Commands

`nano` is a simple command-line text editor commonly used on Linux systems. It is easier for beginners than editors such as `vi` because the commonly used shortcuts are displayed at the bottom of the editor.

---

## 1. Open or Create a File

```bash
nano filename.txt

Opens an existing file or creates a new file if it does not exist.


## 2. `Enter Text`

After opening a file with nano, you can start typing immediately.

Unlike vi, nano does not require switching between Insert Mode and Normal Mode.

## 3. `Save a File`

Press:

Ctrl + O

Nano will ask for the filename.

Press:

Enter

to confirm the filename.


## 4. `Exit Nano`

Press:

Ctrl + X

If there are unsaved changes, nano will ask whether you want to save them.



## 5. `Search Text`

Press:

Ctrl + W

Enter the text you want to search for and press Enter.


## 6. `Cut a Line`

Press:

Ctrl + K

This cuts the current line.



## 7. `Paste Text`

Press:

Ctrl + U

This pastes previously cut text.



## 8. `Undo`

Press:

Alt + U

Undo the previous change.



## 9. `Redo`

Press:

Alt + E

Redo a previously undone change.



## 10. `Go to a Specific Line`

Press:

Ctrl + _

Enter the line number and press Enter.



## 11. `Display Help`

Press:

Ctrl + G

Displays the nano help screen and available keyboard shortcuts.



🧪 Basic Nano Workflow

A simple workflow for creating and editing a file:

nano filename.txt
      ↓
Enter or edit text
      ↓
Ctrl + O
      ↓
Enter
      ↓
Ctrl + X
      ↓
File saved and editor closed
