# Linux `kill` Commands & Signals

Linux uses signals to communicate with and control running processes. The `kill` command is commonly used to send signals to processes using their Process ID (PID).

---

## 1. Find a Process ID

Before sending a signal to a process, its PID can be identified using commands such as:

```bash
ps

## 2. `kill`

Sends a signal to a process.

### Command
kill PID

Example:

kill 1234

By default, kill sends the SIGTERM signal.



## 3. `SIGTERM — Signal 15`

SIGTERM requests that a process terminate gracefully.

kill -15 PID

or:

kill -SIGTERM PID

Purpose:

1.Requests a process to terminate.
2.Allows the process to perform cleanup before exiting.
3.Usually preferred before using SIGKILL.


## 4. `SIGKILL — Signal 9`

Forces a process to terminate immediately.

kill -9 PID

or:

kill -SIGKILL PID

Purpose:

1.Immediately terminates the process.
2.Cannot be caught, blocked, or ignored by the process.
3.Should generally be used only when normal termination does not work.


## 5. `SIGHUP — Signal 1`

Sends a hang-up signal to a process.

kill -1 PID

or:

kill -SIGHUP PID

Depending on the application, SIGHUP may cause a process to reload its configuration or terminate.


## 6. `List Available Signals`

Linux provides a list of available signals:

kill -l

Example signals include:

1   SIGHUP
2   SIGINT
9   SIGKILL
15  SIGTERM


## 7. `SIGINT — Signal 2`

Interrupts a foreground process.

kill -2 PID

The same signal is commonly generated by pressing:

Ctrl + C

in a terminal.


## 8. `pkill`

Terminates processes based on their name instead of requiring a PID.

pkill process-name

Example:

pkill firefox

Use this carefully because it can affect multiple processes with the same name.


## 9. `killall`

Sends a signal to processes matching a specified name.

killall process-name

Example:

killall firefox

Use this command carefully because multiple processes can be affected.


🧪 Example with a Test Process

A harmless background process can be created for practice:

sleep 300 &

Find its PID:

ps

Then terminate it gracefully:

kill PID

Replace PID with the actual process ID.

The process can then be verified using:

ps -p PID
